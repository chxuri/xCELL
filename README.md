# xCELL
* **Made by:** Rimma Mamedova, Divija Mondal, Nikithaa Satish
* Users can login to save their progress.
* _xCELL_ provides users with a way to visualize all the organelles  inside a cell, learn the jobs of each organelle, and take notes as they go, which are saved to their account and can be accessed later on.
